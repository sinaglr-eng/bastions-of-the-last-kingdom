# FR-011 — Boss chests and Commander artifacts

The Commander now has Equipment, Skills, Chests and Sets sections. The canonical catalog is `data/commander-artifacts.json`: 48 artifacts, six cumulative six-piece sets, ten equipment slots and five chest tiers. All alliances share the account collection. The three equipment presets contain artifacts only.

Every verified boss death creates one chest identified by run and enemy spawn. The chest remains locked until its wave finishes, or the defense ends. Campaign bosses award tiers I–V. Endless bosses award at least tier IV, and all bosses at wave 100 or later award tier V. Guest and Developer play do not grant permanent rewards. Existing scores, achievements, XP, medals, skill purchases and saved defenses are preserved.

Chests open individually or five at a time in Commander. The server owns the seeds, rarity pools, new-item preference, guarantees, duplicate Dust conversion and crafting gates. A durable receipt and vault revision make requests idempotent and prevent competing devices from spending the same rewards twice. A pending client request retains its request ID across reconnects. The last opening can be inspected after reload. Opening never automatically equips an item.

New account defenses negotiate artifact version 1 and freeze the server-owned equipment in their initial snapshot and run record. Cached clients and older defenses retain empty equipment. Changes to account equipment cannot alter a running defense. The deterministic combat state serializes artifact damage pools, freeze cooldowns, independent random state and one-time Architect healing. Artifact proc damage does not trigger itself or duplicate existing Blood Wrath scaling. Native immunity and target restrictions remain effective. Attack range bonuses exclude aura and splash footprints; damage, speed, range, control and resource caps are centralized in `game/core/artifacts.js`.

The existing canonical local gallery includes an Artifacts tab with all 48 pictures, properties, rarity, slot, crafting values, set composition, cumulative thresholds and complete set totals. Each exact original PNG and recorded generation prompt remains local. Feedback drafts are keyed by artifact ID plus the original image SHA-256 and can be exported. They are proposals, not automatic game edits or appearance approval records. The gallery and original images are excluded from game publication.

Runtime artwork comprises 48 individual artifacts, ten closed/open chest images, six set illustrations, Relic Dust and a Commander body. The local source manifest is `artifacts/fr011/art-manifest.json`; the public runtime manifest contains only delivery images and hashes. Artwork was generated with built-in image generation and visually checked by agents; no separate human appearance approval is asserted.

Validation includes the full existing regression suite, actual authenticated Worker replay, frozen equipment negotiation, chest locking and defeat release, receipt retry and stale revisions, exact crafting costs, set composition, all three alliances, deterministic save/restore, proc damage budgets and chest guarantees. Browser QA covers iPad 13-inch landscape and portrait, equipment confirmation, set equip, five-chest opening and the local gallery.
