# Padesát vln skřetí kampaně

Předloha: [Gem TD](https://dota2.fandom.com/wiki/Gem_TD). Názvy, číselné parametry a přesné načasování jsou adaptací naší hry. Tento přehled vychází přímo z aktuálních data/enemies.json a data/waves.json. Vlny ani nepřátelé se při jeho vytváření nemění.

Varianta se losuje jednou pro celou skupinu. U vln 31, 35 a 36 jde o magickou **nebo** fyzickou imunitu podle varianty, nikoli současně ani o přepínání během boje. Vlny 38 a 50 mají varianty s odlišnými efekty, rozepsané níže. Běžný armor je součástí statistik všech jednotek; jako zvláštní efekt je uveden pouze těžký pancíř.
