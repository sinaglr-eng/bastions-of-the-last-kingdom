# Combat, Music and Developer Console — 0.3.26

The release implements the agreed combat revision recovered from the champion-evolution discussion, together with the user's approval of independent five-second poison stacks and the complete MVP system. The authoritative current numeric rules, stable family mappings, defense ordering, pause behavior and event contracts are documented in [COMBAT_RULES.md](COMBAT_RULES.md).

The live roster has only Physical, Magical and Holy damage. Armor affects all three; Holy bypasses damage immunity while evasion, shields and Shell still apply. The former Ranger airborne-defense bypass and magical-resistance mechanics are removed. Enemy healing, evasion, cloak, reactive armor, Shell growth and the specified champion abilities use explicit runtime overrides. Archived balance JSON and original reference copy remain preserved; current guide copy describes the playable overrides.

MVP uses actual health removed in each wave, including owned DOT and secondary damage, with ten levels, strongest armor reduction, maximum-level ally support and maximum ingredient inheritance. Per-defender pause stops new attacks and offensive auras while preserving already launched attacks, existing DOT and support. Developer Console uses the same real Game/combat APIs and private run-local rule/data overrides; activation permanently excludes that run from statistics.

The approved audio delivery contains 113 MP3 files: 92 existing allied voice clips, six music tracks and 15 attack effects. Runtime routing separates actual cosmetic fire/frost/lightning effects from the three defense classes, preserves silence for DOT/passive damage, and keeps audio randomness separate from combat. Source receipts and original recorded prompts remain the provenance record; runtime tests do not claim independent listening-quality certification.

Approved 3D models, portraits, their family/rank IDs, original images and recorded assets are not regenerated by the combat revision. Main workspace history remains separate from this isolated release checkout.

Meaningful regression evidence exercises all 86 playable defender profiles, all 40 basic rank merges, all 38 champion crafts, actual armor/immunity resolution, independent poison expiry and ownership, overkill, MVP awards, pause, current wave intelligence, actual DPS, critical-hit timing, audio lifecycle and Console isolation. The final release proof records exact test totals and source/media hashes; this document is the implementation guide rather than a substitute for that proof.
