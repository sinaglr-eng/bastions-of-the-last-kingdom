## Approved gameplay changes

The preserved [balance proposal](../design/audit-20261018-v046/balance/BALANCE_PROPOSAL_20261018.md), [approval](../design/audit-20261018-v046/balance/approval.json) and [B07 mapping](../design/audit-20261018-v046/vfx/mapping.json) are the source decisions. Their original preparation-time statements about deferred implementation remain historical evidence. The table below describes the current implementation.

| Decision | Implemented behavior |
| --- | --- |
| B01 — Personal MVP | Ten levels remain. Each adds 5% personal damage, for a maximum MVP contribution of +50%; this is not a cap on other buffs. The MVP ally-damage and enemy-armor auras are removed. Award selection and highest-level inheritance remain; saved level ten becomes the new +50% contribution. |
| B02 — Rank VI | Two distinct matching basic rank V defenders must have been freshly drawn and placed in the same completed, unresolved five-slot draft. Earlier retained units, inactive reserves and a carried reserve slot cannot supply the pair. A legal reroll may produce the final pair. Merging resolves that round's keeper choice. Existing rank VI units remain valid; lower-rank rules and the Dwarship recipe are unchanged. |
| B03 — Frozen Celestial | Both direct targeting and its 75% slow aura affect ground enemies only. Direct range is 5 tiles; the separate slow radius is 4.5. Existing slow immunity and the boss multiplier remain. Holy damage does not bypass the companion effect's immunity rules. |
| B04 — Ranger control | Master Ranger, Dark Ranger and Ranger Oathbreaker gain 25% / 30% / 40% slow auras at 3.5 / 3.5 / 4 tiles. Auras affect eligible ground and flying targets, stop on leaving the radius and stop while the source's attacks are paused. The strongest slow applies; bosses retain half strength. Existing anti-air hit effects remain separate. |
| B05 — Role-based range | The approved eight-family and 38-champion range tables are applied. Independent slow, burn, armor, support, gaze and chain radii stay separate from buffed direct targeting range. Archdruid grants +1 range; Nature Spirit and Mother Nature retain the explicitly approved +3. These supports have a 5-tile radius and use the strongest bonus. |
| B06 — Dwarven armor auras | Dwarf Firebomber / Dwarf Griffin bomber / Dwarship provide 20 / 35 / 45 flat armor reduction at 4 / 4.5 / 5.5 tiles. The strongest flat reduction applies, with armor floored at zero. Dwarship retains its separate 64-point, four-second hit debuff. Champion armor auras remain; the removed aura is the MVP contribution. |
| B07 — Combat effects | Separate attack, proc, aura and target-status channels read resolved combat events and effective current state. Moving authored anchors, actual chain/fork/bounce paths, bounded poison clouds, burn versus aura heat, control cues and positive-only healing feedback preserve source and target visibility. One combat clock governs pause and speed; reduced motion suppresses repeated motion/flash. Detailed effects have caps and lightweight paths, with cleanup on expiry, hiding, death, reset and teardown. Presentation does not roll gameplay RNG or write combat outcomes. |

Current captions, inspected statistics, Help and rank guidance follow these rules. The balance [implementation receipt](../design/audit-20261018-v046/balance/implementation-validation.json) records 319 focused checks. The final physical-release regression reads all four dragon mouths, Thunderbird and Archangel through the production CombatEffects caller, preventing fallback-height releases. Actual CombatManager/status/effect integration checks also cover failed hits, poison-stack coalescing, flying height, coarse combat frames, healing amounts, pause, reduced motion, disposal and unchanged simulation state.

[The versioned provenance](../public/assets/geometric/approved-enemies-v6/provenance.json) records every file hash, approval digest and motion source. The rejected recoloring/material proposal is excluded, as recorded in the [material decision](../output/design/approved-model-motion-v046-20261018/material-review-v1-user-decision-20261018.json). Private runtime instances provide living movement for all 140 identities: shared family attacks across basic ranks I–VI, champion attacks/support motion, and enemy walking, running or flight. Actual enemy deaths start one-shot death motion from the rendered pose and clean up with the existing battlefield lifecycle.

The [enemy approval](../output/design/approved-model-motion-v046-20261018/enemies-v6-user-approval-20261018.json), [motion approval](../output/design/approved-model-motion-v046-20261018/motion-analysis-v1-user-approval-20261018.json), specifications and [workshop receipt](../output/design/approved-model-motion-v046-20261018/implementation.json) are preserved source evidence. ## Basic defenders book

The Basic defenders chapter now shares the champion book's two-leaf structure: an eight-family index with 48 rank choices on the left and one selected rank's portrait, statistics, description and abilities on the right. All three functional filters remain. Filtered previous/next rank navigation, selection, keyboard actions, disclosure state and index scrolling survive refreshes. Basic rank state remains independent of champion selection and pinning. No static page counters return.

At narrow widths, **Defender index / Selected rank** switches between the same leaves.
