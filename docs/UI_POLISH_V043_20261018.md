# UI polish 0.4.3 — 18 October 2026

This follow-up implements the 30 comments made against release 0.4.2. It gives the five recruits more portrait space, simplifies the Recipes book, makes recipe inspection and creation direct, replaces the MVP award beam with confetti and stars, and improves field-note readability. Interface copy and this report are in English.

## Scope and invariants

Viewing another rank or following a champion ingredient changes only the planning view. It never upgrades the actual defender, changes its foundation, invents an ingredient, rolls a hidden recruit or consumes RNG. All Create actions use the existing exact allocation, actual anchor and current inventory validation key. The intermediate Combination preview sheet and its confirmation step have been removed. An initial map-badge activation selects the real foundation and opens recipe details; a second accepted pointer activation creates only while its exact token remains current.

This release changes presentation and interaction, not campaign balance, damage formulas, recipe ingredients, resource costs, saves or statistics rules. Original approved models, audio, reference sheets, historical portraits, prompts and review records remain preserved. The 0.3.31 recovery points remain available.
