# UI refinements 0.4.4 — 18 October 2026

This follow-up implements the 15 comments made against 0.4.3. It improves command and defender readability, gives the recipe book actual shaped paper and a visible fold, refines the illustrated wave atlas, and adds outcome scenes based on approved character identities. Current UI copy and this report are in English.

**Release status: published and verified.** Release [`6330f1decb1f953c2fa12318e3c47f48d4232bb9`](https://github.com/sinaglr-eng/bastions-of-the-last-kingdom/commit/6330f1decb1f953c2fa12318e3c47f48d4232bb9) passes all **1,534 tests**, the **197-module** production build, [Pages CI](https://github.com/sinaglr-eng/bastions-of-the-last-kingdom/actions/runs/39135501434), **202 public GET/hash checks** and native public book/atlas review. The release tag is `v0.4.4`.

## Scope and preservation

The work uses isolated source baseline `836a541014a22b845b6b54b870ce7df7e5d143db`. The saved MAIN snapshot protects 771 paths. Mirror/staging helpers use explicit task allowlists and refuse changed payloads, unexpected MAIN content, symlinks, out-of-scope paths and changed Git indexes. README and CHANGELOG require reviewed three-way candidates so pre-existing MAIN documentation survives. Preparing these helpers does not apply a mirror, stage files, commit or deploy.

No campaign balance, core combat calculations, recipe ingredients, exact rank allocation, hidden recruits, currency costs, save contracts or statistics rules change. The renderer additions are cosmetic: a marker follows the existing individual `attackPaused` state and the existing command controls move. All previous approved portraits, 50 FRONT derivatives, models, audio, source concepts, prompts and historical records remain immutable. New paper SVGs and two versioned outcome images are additions. Existing recovery points remain available.
